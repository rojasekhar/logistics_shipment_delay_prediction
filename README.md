# \# Logistics Shipment Delay Prediction

# 

# \## Problem

# Predict shipment delays to improve delivery performance.

# 

# \## Data

# \- Logistics records with features: distance, weather, traffic

# \- Target: delayed (0/1)

# 

# \## Approach

# \- Preprocessing: feature engineering (distance buckets)

# \- Models: Logistic Regression, XGBoost

# \- Evaluation: F1-score, Precision, Recall

# 

# \## Results

# \- Achieved F1-score of 0.81

# \- Improved delivery performance tracking

# 

# \## Deployment

# \- Integrated predictions into Power BI dashboards
